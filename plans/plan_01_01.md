# Plan 01-01: Backend Configuration & Database Setup

## Objective
Set up base configuration files and database connection improvements.

## Files to Modify

### 1. `Backend/config.js` — Add JWT config
- Add `jwt` export to the existing exports object
- Fields: `secret`, `accessExpiry: "15m"`, `refreshExpiry: "7d"`, `cookieExpiry: 7 * 24 * 60 * 60 * 1000`
- Read `JWT_SECRET` from env with fallback `"fallback_dev_secret"`

### 2. `Backend/database/index.js` — Update connection handling
- Ensure `dbURI` falls back to `mongodb://127.0.0.1:27017/stockly` when no credentials are provided
- Add connection event listeners: `connected`, `error`, `disconnected`
- Each listener should log appropriate messages via `console.log` / `console.error`

### 3. `Backend/.env` — Add environment variables
```
PORT=8080
NODE_ENV=development
JWT_SECRET=stockly_dev_secret_key_2024
DB_NAME=stockly
DB_HOST=127.0.0.1
DB_PORT=27017
DB_USER=
DB_USER_PWD=
CORS_URL=http://localhost:5173
```

## Acceptance Criteria
- [ ] Backend starts without errors
- [ ] MongoDB connects with fallback URI when no credentials
- [ ] Connection event listeners log correctly
- [ ] JWT config is importable and has correct values
- [ ] Existing functionality is not broken

## Dependencies
- MongoDB running locally on port 27017
- No new npm packages needed
