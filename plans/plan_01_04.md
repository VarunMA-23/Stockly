# Plan 01-04: Backend Category CRUD

## Objective
Create Category model, controller, and routes with soft-delete and subcategory support.

## Files to Create

### 1. `Backend/models/categoryModel.js`
```js
Schema fields:
- name: String, required, unique, trim: true
- description: String, default ""
- image: String
- parentCategory: ObjectId ref "Category", default null
- isActive: Boolean, default true
- timestamps: true

Index: { name: 1 } unique
```

### 2. `Backend/controllers/categoryController.js`
Functions (all using `express-async-handler`):
- `getCategories` — Find all, support `?isActive=true` filter, support `?parent=null` (get root categories)
- `createCategory` — Validate name unique, create, return doc with 201
- `getCategoryById` — Find by ID, 404 if not found
- `updateCategory` — Find by ID, update fields, return updated doc
- `deleteCategory` — Soft-delete: set `isActive = false` (admin only)

### 3. `Backend/routes/categoryRoutes.js`
```
GET    /api/categories     → protect, getCategories
POST   /api/categories     → protect, authorize("admin", "manager"), createCategory
GET    /api/categories/:id → protect, getCategoryById
PUT    /api/categories/:id → protect, authorize("admin", "manager"), updateCategory
DELETE /api/categories/:id → protect, authorize("admin"), deleteCategory
```

## Acceptance Criteria
- [ ] Admin & manager can create categories
- [ ] All roles can view categories
- [ ] Admin can soft-delete (deactivate) categories — sets `isActive = false`
- [ ] Subcategory support works via `parentCategory` ref
- [ ] Category list filters by `?isActive=true` and `?parent=null`
