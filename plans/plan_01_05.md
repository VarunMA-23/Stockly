# Plan 01-05: Backend Product CRUD

## Objective
Create Product model, controller, and routes with pagination, search, and filtering.

## Files to Create

### 1. `Backend/models/productModel.js`
```js
Schema fields:
- sku: String, required, unique, trim: true
- name: String, required, trim: true
- category: ObjectId ref "Category", required
- description: String, default ""
- buyingPrice: Number, required, min: 0
- sellingPrice: Number, required, min: 0
- mrp: Number, required, min: 0
- unit: String enum ["piece", "kg", "liter", "pack", "box"], default "piece"
- quantity: Number, default 0, min: 0
- minStock: Number, default 5
- maxStock: Number, default 100
- location: String
- supplier: ObjectId ref "Supplier", default null
- barcode: String, sparse: true
- image: String
- expiryDate: Date
- isActive: Boolean, default true
- timestamps: true

Indexes:
- { sku: 1 } unique
- { name: "text", description: "text" } for text search
```

### 2. `Backend/controllers/productController.js`
Functions (all using `express-async-handler`):
- `getProducts` — Paginated list. Support query params:
  - `?search` — regex match on name/sku (case-insensitive)
  - `?category` — filter by category ObjectId
  - `?isActive` — filter by active status
  - `?minStock` — filter where quantity <= minStock
  - `?page`, `?limit` — pagination (default: page=1, limit=20)
  - Populate category field
  - Response format: `{ products: [], page, pages, total }`
- `createProduct` — Validate SKU unique, auto-generate SKU `PRD-{random8chars}` if empty, create, return 201
- `getProductById` — Find by ID, populate category, 404 if not found
- `updateProduct` — Find by ID, update fields, return updated doc
- `deleteProduct` — Soft-delete: set `isActive = false` (admin only)

### 3. `Backend/routes/productRoutes.js`
```
GET    /api/products     → protect, getProducts
POST   /api/products     → protect, authorize("admin", "manager"), createProduct
GET    /api/products/:id → protect, getProductById
PUT    /api/products/:id → protect, authorize("admin", "manager"), updateProduct
DELETE /api/products/:id → protect, authorize("admin"), deleteProduct
```

## Acceptance Criteria
- [ ] Admin & manager can create products
- [ ] SKU is auto-generated if not provided (format: `PRD-xxxxxxxx`)
- [ ] All roles can view products with pagination
- [ ] Search by name/sku works with case-insensitive regex
- [ ] Filter by category works
- [ ] Filter by minStock works (low stock products)
- [ ] Product list is paginated with page/pages/total response format
- [ ] Soft-delete works (product set to inactive)
