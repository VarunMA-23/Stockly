# Plan 01-06: Frontend Foundation — Types, API Service, Auth Service

## Objective
Create shared TypeScript types, Axios instance with interceptors, and auth service layer.

## Files to Create

### 1. `Frontend/src/app/types/index.ts`
Export TypeScript interfaces:
- `User`: _id, name, email, role, store?, isActive
- `Store`: _id, name, address?, phone?, gstin?
- `Category`: _id, name, description?, parentCategory?, isActive
- `Product`: _id, sku, name, category, description?, buyingPrice, sellingPrice, mrp, unit, quantity, minStock, maxStock, location?, barcode?, image?, expiryDate?, isActive, createdAt, updatedAt
- `PaginatedResponse<T>`: data, page, pages, total

### 2. `Frontend/src/app/services/api.ts` — Axios instance
```ts
// Create axios instance with:
// baseURL = import.meta.env.VITE_API_URL || "http://localhost:8080/api"

// Request interceptor:
// - Attach Authorization: Bearer <accessToken> if token available in memory

// Response interceptor:
// - If 401 received, attempt refresh via POST /api/users/refresh
// - If refresh succeeds, retry original request with new token
// - If refresh fails, clear auth state, redirect to /login
// - Export the instance (default export or named export)
```

Token storage: Use a module-level variable (in-memory) for the access token. This is more secure than localStorage.

### 3. `Frontend/src/app/services/auth.ts`
Functions:
- `login(email, password)` → `POST /users/login` → returns `{ user, accessToken }`
- `register(name, email, password, storeName?)` → `POST /users/register` → returns `{ user, accessToken }`
- `logout()` → `POST /users/logout`
- `getProfile()` → `GET /users/profile`
- `refreshToken()` → `POST /users/refresh` → returns `{ accessToken }`

Each function should update the in-memory token variable in `api.ts`.

## Acceptance Criteria
- [ ] TypeScript types are complete and match backend response shapes
- [ ] Axios instance attaches Bearer token on requests
- [ ] Response interceptor retries on 401 with refresh token
- [ ] Auth service functions call correct endpoints
