# Plan 01-07: Frontend Auth UI — AuthContext, Login, Signup, Topbar, App

## Objective
Wire up the frontend auth flow: AuthContext provider, Login/Signup page wiring, Topbar user display, and App.tsx auth state integration.

## Files to Create

### 1. `Frontend/src/app/context/AuthContext.tsx`
React context providing:
- `user: User | null`
- `isAuthenticated: boolean`
- `isLoading: boolean`
- `login(email, password): Promise<void>` — calls auth.login, stores user + token in context
- `register(name, email, password, storeName?): Promise<void>` — calls auth.register, stores user + token
- `logout(): void` — calls auth.logout, clears user + token
- `error: string | null`

**Initialization on mount**:
- Attempt POST /api/users/refresh (cookie sent automatically)
- If success → GET /api/users/profile → set user
- If fail → set isAuthenticated = false

## Files to Modify

### 2. `Frontend/src/main.tsx`
- Wrap `<App />` with `<AuthProvider>`

### 3. `Frontend/src/app/App.tsx`
- Import `useAuth()` from AuthContext
- Replace hard-coded `isAuthenticated = true` with `isAuthenticated` from context
- Show loading spinner while auth state initializes
- Pass `onNavigate` to page components that need it
- Redirect to `/login` when not authenticated

### 4. `Frontend/src/app/pages/Login.tsx`
- Import `useAuth()` context
- Import `authService.login()` from services (or use context's login)
- On submit: call `login(email, password)`
- Show validation errors from API below form fields
- On success: navigate to `/` (dashboard)
- Google sign-in button: keep but with toast "Coming soon" on click

### 5. `Frontend/src/app/pages/Signup.tsx`
- Import `useAuth()` context
- Import `authService.register()` from services (or use context's register)
- On submit: call `register(name, email, password, storeName?)`
- Auto-login on success (tokens already returned), navigate to `/`
- Show field-level validation errors
- Keep store name field

### 6. `Frontend/src/app/components/Topbar.tsx`
- Import `useAuth()` context
- Replace hard-coded "John Doe" with `user.name`
- Replace store placeholder with `user.store?.name`

## Acceptance Criteria
- [ ] Login form calls API and navigates to dashboard on success
- [ ] Signup form calls API and auto-logs in
- [ ] Validation errors from API display on form
- [ ] Auth state persists across page refresh (via refresh token flow)
- [ ] Topbar shows real user name and store
- [ ] Unauthenticated users redirect to /login
- [ ] Logout clears auth state and redirects to /login
