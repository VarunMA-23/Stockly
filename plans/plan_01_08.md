# Plan 01-08: Frontend Categories Page

## Objective
Create the Category management page with full CRUD UI, service layer, and custom hook.

## Files to Create

### 1. `Frontend/src/app/services/categories.ts`
API functions:
- `getCategories(params?: { isActive?, parent? })` → `GET /categories` → returns array of categories
- `getCategoryById(id)` → `GET /categories/:id`
- `createCategory(data)` → `POST /categories`
- `updateCategory(id, data)` → `PUT /categories/:id`
- `deleteCategory(id)` → `DELETE /categories/:id`

### 2. `Frontend/src/app/hooks/useCategories.ts`
Custom hook wrapping categories service:
- State: `categories`, `loading`, `error`
- Fetch on mount
- Return: `{ categories, loading, error, refetch }`

### 3. `Frontend/src/app/pages/Categories.tsx`
Category management page with:
- Table listing all categories with columns: Name, Description, Status (Active/Inactive badge), Parent Category
- "Add Category" button → opens modal/dialog with form
- Form fields: Name (required), Description, Parent Category (dropdown from API, shows root categories)
- Row actions: Edit (opens modal pre-filled), Deactivate (with confirmation dialog, calls delete endpoint)
- Breadcrumb: Settings > Categories (or sidebar nav item)
- Subcategory support: render as indented tree or show parent name in table
- Loading state (shadcn Skeleton)
- Empty state ("No categories found")
- Error state with retry button

## Acceptance Criteria
- [ ] Category list loads from API on mount
- [ ] Create category modal works end-to-end
- [ ] Edit modal pre-fills and updates correctly
- [ ] Deactivate (soft-delete) with confirmation works
- [ ] Parent category dropdown shows available root categories
- [ ] Status badges show Active/Inactive correctly
- [ ] Loading, empty, and error states handled
