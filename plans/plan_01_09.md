# Plan 01-09: Frontend Product Form

## Objective
Create the product service, custom hook, and the Create/Edit product form page.

## Files to Create

### 1. `Frontend/src/app/services/products.ts`
API functions:
- `getProducts(params)` → `GET /products` with query params `{ search?, category?, page?, limit?, minStock?, isActive? }` → returns `PaginatedResponse<Product>`
- `getProductById(id)` → `GET /products/:id`
- `createProduct(data)` → `POST /products`
- `updateProduct(id, data)` → `PUT /products/:id`
- `deleteProduct(id)` → `DELETE /products/:id`

### 2. `Frontend/src/app/hooks/useProducts.ts`
Custom hook wrapping products service:
- State: `products`, `loading`, `error`, `page`, `pages`, `total`
- `search` — current search term
- `setSearch` — update search (with debounce 300ms before refetch)
- `setPage` — change page number
- `refetch` — re-run the query
- Return: `{ products, loading, error, page, pages, total, search, setSearch, setPage, refetch }`

### 3. `Frontend/src/app/pages/ProductForm.tsx`
Create/Edit product form with two modes:
- **Create mode**: `POST /products` on submit
- **Edit mode**: `PUT /products/:id` on submit, pre-fill from existing product data

**Fields**:
- SKU: Text input + "Auto-generate" button (generates `PRD-xxxxxxxx` on frontend or leaves empty for backend)
- Name: Text input (required)
- Category: Dropdown select from `GET /api/categories` (required)
- Description: Textarea
- Buying Price: Number input (required, > 0)
- Selling Price: Number input (required, > 0)
- MRP: Number input (required, > 0)
- Unit: Dropdown (`piece`, `kg`, `liter`, `pack`, `box`)
- Quantity: Number input (>= 0)
- Min Stock: Number input
- Max Stock: Number input
- Location: Text input
- Barcode: Text input
- Image URL: Text input
- Expiry Date: Date picker

**Frontend validation**:
- Required fields: name, category, buyingPrice, sellingPrice, mrp
- Prices > 0
- Quantity >= 0

**Flow**:
- Uses `react-hook-form` (already installed) with shadcn `Form`, `Input`, `Select` components
- On save: call API, navigate back to inventory/product list page
- Cancel: navigate back without saving

**Integration**:
- Inventory page gets an "Add Product" button that navigates to `ProductForm` (create mode)
- Each product row in inventory gets an "Edit" button that navigates to `ProductForm` (edit mode with product ID)

## Acceptance Criteria
- [ ] Create mode: form validates required fields, calls POST, navigates to list on success
- [ ] Edit mode: pre-fills from existing product, calls PUT, navigates to list on success
- [ ] SKU auto-generate button works
- [ ] Category dropdown fetches from API
- [ ] Frontend validation shows errors on required fields
- [ ] API validation errors display on form
- [ ] Cancel returns to product list without changes
