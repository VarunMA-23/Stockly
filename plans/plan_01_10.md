# Plan 01-10: Frontend Inventory Page & Dashboard KPI Wiring

## Objective
Wire the existing Inventory.tsx page to real API data with search, pagination, and filtering. Wire Dashboard.tsx basic KPIs to real API counts.

## Files to Modify

### 1. `Frontend/src/app/pages/Inventory.tsx` — Wire to real data

Replace mock data with real API integration:

**Data fetching**:
- Use `useEffect` + `useProducts` hook to fetch from `GET /api/products`
- Accept query params: `search`, `category`, `page`, `limit`, `isActive`

**UI components**:
- **Search bar**: Wire input to `?search=` param with debounce (300ms)
- **Category filter**: Dropdown populated from `GET /api/categories`, wires to `?category=` param
- **Pagination**: Prev/Next buttons or page numbers, update `?page=` param
- **Status badges**: Map `isActive` field to Active (green) / Inactive (red/gray) badges

**Loading state**:
- Show shadcn `Skeleton` components while loading

**Empty state**:
- Show helpful message when no products found ("No products match your search" / "Add your first product")

**Error state**:
- Show error message with retry button

**Keep as-is**:
- Grid/list toggle (visual-only for now)
- Table columns and layout

### 2. `Frontend/src/app/pages/Dashboard.tsx` — Wire basic KPIs

Replace mock KPI numbers:
- **Total Products**: Replace hard-coded number with count from `GET /api/products` (use `total` from paginated response, or fetch all with small limit)
- **Low Stock Items**: Replace hard-coded number with count from `GET /api/products?minStock=true` (use `total` from response)

**Keep as mock** (out of scope for Phase 1):
- Charts (line/bar)
- AI insights
- Recent activity feed
- Revenue/cost numbers

## Acceptance Criteria
- [ ] Active product list loads from API on mount
- [ ] Search input filters results with 300ms debounce
- [ ] Category filter dropdown populated from API
- [ ] Pagination controls work (prev/next)
- [ ] Loading state shows skeleton components
- [ ] Empty state shows helpful message
- [ ] Error state shows retry button
- [ ] Dashboard shows real total product count
- [ ] Dashboard shows real low stock count
